# 兩步學習單

依本專案 `textbook-to-visual-worksheet` 正式skill校正的老師跟做提示工具。比賽頁面不附skill檔案或規範連結，規則整合於提示詞。

1. 指定年級、科目、版本、單一活動／課次及來源頁。自然按活動、社會按課；三部分是同一活動／課內重組。
2. NotebookLM逐段執行來源確認、教材分析、三部分重組，保留原始回答及引用，回原頁核對。
3. 確認學習目標、格數計算方式、難度、逐字完整題幹與風格，再到ChatGPT出學生圖。
4. 核對實圖後，依實際位置製作答案表及同圖教師答案版；圖片等比例封裝學生／教師PDF，分別保存。
5. 所有作品標「待教師審核」。QA區分已機器核查、尚待人工核查、未通過；未試印、試作或教師確認不得寫成完成。

16格只是可調建議；支援整份總計或每部分各計，每部分24格即72格，必要時拆頁不減題。難度與格數獨立；尋找關聯性時至少50%填空評量教材支持的關係。高年級同樣採三部分圖像填空，既有C挑戰版僅為歷史案例。

網站無AI API，不登入、不上傳、不自動操作NotebookLM或ChatGPT、不背景監看。自動模式僅在使用者本次指定來源資料夾、輸出位置、範圍及授權操作兩個服務，且代理人工具齊備時成立；此網站僅供手動複製提示詞。缺工具停在該步並交提示包，不冒稱完成。

資料存在目前瀏覽器localStorage；保留舊教材文字，舊版模糊格數改為16格建議，清除舊QA勾選。匯出Markdown為提示包，並非已生成圖片或PDF。範例是歷史紀錄，不因網站更新而取得新驗收。

本機預覽：在儲存庫根目錄執行 `python -m http.server 8765`，開啟 http://localhost:8765/ 。GitHub Pages使用main分支根目錄，無建置步驟。未包含教材PDF或私人帳戶資訊。

教師確認方式可選「逐關確認」或「略過中間確認，AI檢核後交付」。後者不等於教師審核通過，也不授權外部服務自動操作；設定同步帶入提示詞與匯出包。

## 教材直接附到 ChatGPT

主畫面：開啟ChatGPT並附上教材PDF → 複製學生學習單指令、貼到同一對話 → 學生圖完成後，附上原圖並貼教師版指令。網站不讀取或上傳PDF、不代為操作ChatGPT。設定與NotebookLM逐步流程收在摺疊區。範圍不明或多課先指定單一活動／課次，不將整冊合併成一張。
