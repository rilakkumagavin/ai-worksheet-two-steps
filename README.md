# 兩步學習單｜教師簡化版

NotebookLM 拆解教材 → ChatGPT 製作圖片式填空學習單。

純前端網站，提供低、中、高年級提示詞、教材底稿帶入、學生與教師圖製作指令、修正指令、人工檢查紀錄及Markdown製作包匯出。

## 使用

1. 選年級、科目與課次；複製提示詞到NotebookLM，選取本課教材，開啟引用頁面核對。
2. 將已核對拆解貼回第二步；複製圖片提示詞到ChatGPT，產生學生圖並檢查，再編輯同版教師答案圖。

網站不呼叫AI API，不自動登入或上傳資料。進度只存在目前瀏覽器的localStorage，受限時仍可手動複製與匯出。修改教材、年級或設定會清除人工檢查勾選，避免沿用舊紀錄。

## 本機預覽

在專案根目錄執行：

```powershell
py -m http.server 8765 --directory "網站/兩步驟圖像學習單"
```

瀏覽 http://localhost:8765/ 。可直接開啟index.html，但瀏覽器可能限制剪貼簿功能；正式站建議HTTPS。

2026-10-21使用四上社會1-2「家鄉的地形」NotebookLM進行新一輪教材拆解，對照本機課本印刷20–23頁，修正教冊頁碼混淆，再在ChatGPT網頁實際生成學生圖片。8格中3格為生活關係或互動。圖片與驗收結果見範例目錄。

2026-10-21追加中年級注音出圖實測，結果見範例/中年級注音實測.md。網站新增注音開關，低、中年級預設加入注音，高年級預設不加；也可手動選擇。注音提示詞指定注音芫荽Bpmf Iansui；精確字型須使用實際字型檔排版，圖片生成不能保證字型或多音字讀音。字型來源：https://github.com/ButTaiwan/bpmfvs/releases 。

## GitHub Pages

部署根目錄為儲存庫根目錄，使用main分支。所有網站資源均為相對路徑，無建置步驟、後端或金鑰。公開內容為自寫教學指令、摘要、生成圖片與實測紀錄；不包含教材PDF、私人Notebook網址、帳號資訊或聊天截圖。

生成圖片是已完成內容核對的教學草稿；仍需教師確認及實際列印驗收。
