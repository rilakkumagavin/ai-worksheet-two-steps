# 六上社會1-3｜C挑戰版兩步驟實測

日期：2026-10-21。老師已選定〈民主國家政府與人民的關係為何？〉，範圍為課本印刷34–39頁／本機PDF1–6。未處理1-2或40–41頁國民教育探究。

## 1. NotebookLM與教材核對

在老師開好的六上社會Notebook重新送出指定課次的核對指令，取得教師端概念架構、三個教學假設情境的支持論點、頁碼與三級評分規準。對照本機同名課本文字及六張頁面渲染圖逐頁檢查。

確認範圍：34頁人民與政府；35頁中央分工；36頁地方分工；37頁酒駕案例合作；38頁傾聽民意與監督；39頁救助、申訴與補助。

NotebookLM的延伸用語未全數照用：不把經濟補助說成必然補償，不加入本次主文未詳述的法規細節；其「留白三大主幹」建議也未採用，改為學生圖完全不預畫主幹。詳見[來源核對判定](六上1-3來源核對判定.md)。

三個事件均明標為教學假設，依教材原則推理，不冒稱為課本記載的真實事件；也不要求學生猜精確法規裁決。

## 2. ChatGPT實際產生兩張學生圖片

沿用老師既有C挑戰版的設計方向，在ChatGPT網頁實際產生兩張新的圖片。先生成第1頁並下載檢視，再生成第2頁並下載逐題核對，不以先前的舊圖或模型自評充當新實測。

| 檢查項目 | 結果 |
|---|---|
| 課名與課次 | 兩頁均為六上社會1-3正確課名，未沿用1-2標題 |
| 教材範圍 | 第34–39頁，兩張圖均一致 |
| 第1頁任務01 | 核心大問題、完全空白心智圖框、通用檢核、重要連結解釋與課本依據欄齊全 |
| 自主建構 | 無預填主幹、分類、關係箭頭、答案、詞語庫；頁邊插圖未替學生完成架構 |
| 心智圖留白 | 空白框約占紙面一半，明顯比原單頁整合版大；未完全達到原提示詞要求整頁60%，列為版面限制，可依學生需要再增頁或放大 |
| 第2頁任務02–04 | 三個情境與題意正確；各含概念、判斷或建議、理由、頁碼與依據空白 |
| 假設情境標示 | 圖上明示「教學假設情境」，未當作教材史實 |
| 任務05 | 自編情境與問題、參考答案與理由、教材依據空白完整 |
| 任務06 | 延伸提問與作答空間保留，不印出小結或示範理由 |
| 教師答案隔離 | 學生圖無預填參考答案；教師完整架構、可接受論點與三級規準另提供文字檔 |
| 文字與可讀性 | 原圖逐題檢視未見影響題意的漏字或錯字，無注音；行距與書寫線清楚 |
| 圖片格式 | 兩張均接近A4橫式比例；可下載原圖 |
| 真實列印／學生試作 | 尚未完成，不能以螢幕檢查代替 |

結論：完成兩步驟高年級C挑戰版實測與內容檢查；兩張學生圖可作教學草稿。未宣稱已教師定稿、紙本驗收或完成學生試作。教師參考為Markdown文字，未另生成教師答案圖片。
