# 逐格答案與來源

1. 作者受傷、奶奶戴假牙，兩人共同遇到的是【　】。 → 進食不便｜印刷頁15–16｜整合兩項線索
2. 米煮得很軟，是配合兩人不便【　】的需要。 → 咀嚼｜印刷頁15｜行動與目的
3. 反覆描寫換水、加料和久煮，可看出奶奶準備時的【　】。 → 用心｜印刷頁15｜行動推論
4. 料理步驟先後清楚，讓讀者能想像製作的【　】。 → 過程｜印刷頁15｜表達效果
5. 小學受傷與國中矯正，雖情況不同，都使作者需要較【　】的食物。 → 柔軟｜印刷頁15–16｜跨段比較
6. 成年後牙齒已好，仍願共餐，說明吸引他的不只是食物的【　】。 → 味道｜印刷頁17｜跨段推論
7. 作者牙齒變好，奶奶卻更不方便，形成前後的【　】。 → 對比｜印刷頁16–17｜表達方法
8. 奶奶仍把成年作者當小孩，顯示對他的照料一直【　】。 → 不變｜印刷頁17｜變與不變
9. 結合容易餓與吃光的線索，可推知這道料理能帶來【　】。 → 飽足｜印刷頁16｜有據推論
10. 「一邊看、一邊笑」寫出兩個動作【　】發生。 → 同時｜印刷頁17｜句式關係
11. 一碗粥既照顧身體，也承載祖孫的【　】。 → 情感｜印刷頁15–17｜主旨整合
12. 結尾稱奶奶笑容可愛，可推知作者珍惜兩人相處的【　】。 → 回憶｜印刷頁17｜語句與情意

國語開放說法：進食不便可接受不方便吃東西；用心可接受細心、關照；柔軟可接受軟爛；味道可接受美味；對比可接受反差；不變可接受持續；飽足可接受吃飽；情感可接受感情、關愛；回憶可接受時光、記憶。須依完整題意與教材證據判斷。
